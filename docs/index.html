저장 공간

카드 데이터는 이 휴대폰 안의 데이터베이스에만 저장됩니다. 앱을 삭제하면 데이터도 지워지므로, 가끔 [더보기 → 전체 다운로드 · 백업]으로 백업해 두세요. 백업 ZIP은 [등록]에서 다시 불러올 수 있습니다.
